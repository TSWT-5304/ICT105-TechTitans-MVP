## Access Note

The PeerTutor prototype is publicly accessible through GitHub Pages. No account, download, or installation is required.

The recommended starting point is the Role Selection page. Direct dashboard links are also provided so that evaluators can quickly inspect the interface for each user role.

For the best experience, open the prototype using a desktop web browser. The prototype also includes responsive layouts for mobile devices. Authentication, payment processing, payment verification, data storage, and selected dashboard functions are simulated for MVP demonstration and validation purposes.
