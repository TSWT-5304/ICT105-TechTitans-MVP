## Recommended Testing Flow

### Student

1. Open the homepage.
2. Select the Student role.
3. Search and filter tutors.
4. Open a tutor profile.
5. Submit a tutoring request.
6. Check the request status.
7. Complete the simulated payment.
8. View payment history.
9. Leave a review and rating.

### Student Tutor

1. Select the Student Tutor role.
2. Submit a tutor application.
3. Create or review the tutor profile after approval.
4. Open the Tutor Dashboard.
5. Approve or reject an incoming request.
6. View schedules, reviews, earnings, and payment status.

### Administrator

1. Select the Administrator role.
2. Review and approve or reject a tutor application.
3. Manage user accounts.
4. Verify a simulated student payment.
5. Record platform commission.
6. Update the simulated tutor payout.
7. Review dashboard summaries and analytics.
